# AWS: S3 (Simple Storage Service)

S3 is object storage: you store files (objects) in buckets, and access them over HTTP by key. It is durable (designed for 11 nines of durability), scales without capacity planning, and is the base for data lakes, backups, static websites, logs and artifacts. S3 is the most-asked AWS service in interviews.

## Core concepts

| Term | Meaning |
|---|---|
| **Bucket** | A top-level container with a globally unique name, in one region |
| **Object** | A file plus metadata, identified by a **key** (`reports/2026/10/orders.csv`) |
| **Key prefix** | The path-like part of a key. S3 has no real folders; the console just shows them |
| **Version** | With versioning on, every overwrite keeps the previous object |
| **Storage class** | Price and access tier for each object |
| **ARN** | `arn:aws:s3:::bucket` for the bucket, `arn:aws:s3:::bucket/*` for its objects |

## Storage classes

| Class | Use for | Retrieval | Relative cost |
|---|---|---|---|
| **S3 Standard** | Frequently accessed data | Instant | Highest storage price |
| **Intelligent-Tiering** | Unknown or changing access patterns | Instant | Moves objects automatically |
| **Standard-IA** | Infrequent access, still needed quickly | Instant, per-GB fee | Lower |
| **One Zone-IA** | Re-creatable infrequent data | Instant | Lower; one AZ only |
| **Glacier Instant Retrieval** | Archives read once a quarter | Milliseconds | Lower still |
| **Glacier Flexible Retrieval** | Archives | Minutes to hours | Low |
| **Glacier Deep Archive** | Compliance archives | Up to 12 hours | Lowest |

Smaller objects are charged a minimum size in the IA and Glacier classes, so do not store millions of tiny files there.

## Create a bucket and upload

```bash
aws s3 mb s3://orders-exports-prod-123456789012 --region us-east-1

aws s3 cp orders-2026-10.csv s3://orders-exports-prod-123456789012/exports/2026/10/

aws s3 ls s3://orders-exports-prod-123456789012/exports/2026/10/
```

```output
make_bucket: orders-exports-prod-123456789012
upload: ./orders-2026-10.csv to s3://orders-exports-prod-123456789012/exports/2026/10/orders-2026-10.csv
2026-10-27 09:14:02      48213 orders-2026-10.csv
```

Sync a local folder (only changed files are uploaded):

```bash
aws s3 sync ./reports s3://orders-exports-prod-123456789012/reports --delete
```

`--delete` removes remote files that no longer exist locally. Leave it off unless you mean it.

## Secure by default

Current S3 defaults are good, but make sure these are set explicitly in your bucket baseline:

- **Block Public Access** on (account-level and bucket-level). This is the single most important setting.
- **Default encryption**: SSE-S3 (AES-256) or SSE-KMS with a customer key for audit trails.
- **Bucket policy** that denies non-TLS requests.
- **Versioning** on for important data, with MFA delete for production.
- **Object Ownership** set to *Bucket owner enforced* (disables ACLs).

```bash
aws s3api put-public-access-block --bucket orders-exports-prod-123456789012 \
  --public-access-block-configuration \
  "BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true"

aws s3api put-bucket-versioning --bucket orders-exports-prod-123456789012 \
  --versioning-configuration Status=Enabled
```

### Bucket policy that enforces HTTPS

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "DenyInsecureTransport",
      "Effect": "Deny",
      "Principal": "*",
      "Action": "s3:*",
      "Resource": [
        "arn:aws:s3:::orders-exports-prod-123456789012",
        "arn:aws:s3:::orders-exports-prod-123456789012/*"
      ],
      "Condition": { "Bool": { "aws:SecureTransport": "false" } }
    }
  ]
}
```

## Lifecycle rules

Move or delete objects automatically to control cost:

```json
{
  "Rules": [
    {
      "ID": "archive-exports",
      "Status": "Enabled",
      "Filter": { "Prefix": "exports/" },
      "Transitions": [
        { "Days": 30, "StorageClass": "STANDARD_IA" },
        { "Days": 90, "StorageClass": "GLACIER_IR" }
      ],
      "Expiration": { "Days": 365 },
      "NoncurrentVersionExpiration": { "NoncurrentDays": 30 }
    }
  ]
}
```

```bash
aws s3api put-bucket-lifecycle-configuration \
  --bucket orders-exports-prod-123456789012 \
  --lifecycle-configuration file://lifecycle.json
```

## Presigned URLs

Give a user temporary access to one object without making the bucket public. The URL carries the signer's permissions and expires.

```bash
aws s3 presign s3://orders-exports-prod-123456789012/exports/2026/10/orders-2026-10.csv \
  --expires-in 900
```

```output
https://orders-exports-prod-123456789012.s3.us-east-1.amazonaws.com/exports/2026/10/orders-2026-10.csv?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Expires=900&...
```

In code, use boto3 to upload directly from a browser with a presigned PUT:

```python
import boto3

s3 = boto3.client("s3", region_name="us-east-1")
BUCKET = "orders-exports-prod-123456789012"

# Upload from the server
s3.upload_file("orders-2026-10.csv", BUCKET, "exports/2026/10/orders-2026-10.csv")

# Download
s3.download_file(BUCKET, "exports/2026/10/orders-2026-10.csv", "local-copy.csv")

# Presigned upload URL for a browser, valid 5 minutes
url = s3.generate_presigned_url(
    "put_object",
    Params={"Bucket": BUCKET, "Key": "uploads/user-42/receipt.pdf", "ContentType": "application/pdf"},
    ExpiresIn=300,
)
print(url)
```

## Events and replication

- **Event notifications**: S3 can publish `ObjectCreated` events to SQS, SNS or EventBridge, or trigger a Lambda. This is the usual way to process uploaded files. See the Messaging page.
- **Cross-region replication (CRR)** copies objects to another region for disaster recovery.
- **Same-region replication (SRR)** copies to another bucket in the same region, for example into a separate account for backups.

## Static website hosting

S3 can serve a bucket as a static website (HTML, CSS, JavaScript, images) over HTTP at a website endpoint. Use it for simple sites, documentation, or single-page apps.

```bash
BUCKET=my-static-site-123456789012
aws s3 mb s3://$BUCKET --region us-east-1
aws s3 website s3://$BUCKET --index-document index.html --error-document 404.html
aws s3 cp ./dist s3://$BUCKET --recursive --cache-control "max-age=86400"
aws s3api get-bucket-website --bucket $BUCKET
```

```output
{
    "IndexDocument": { "Suffix": "index.html" },
    "ErrorDocument": { "Key": "404.html" }
}
```

The website endpoint looks like `http://my-static-site-123456789012.s3-website-us-east-1.amazonaws.com`.

Public website hosting requires turning off Block Public Access for that bucket and adding a public read policy. That is the one case where a public bucket is intended, so keep it dedicated to public content and never mix in private data:

```json
{
  "Version": "2012-10-17",
  "Statement": [{
    "Sid": "PublicReadForWebsite",
    "Effect": "Allow",
    "Principal": "*",
    "Action": "s3:GetObject",
    "Resource": "arn:aws:s3:::my-static-site-123456789012/*"
  }]
}
```

Website endpoints serve HTTP only. For HTTPS, custom domains, and caching, put **CloudFront** in front of the bucket with Origin Access Control instead. Then the bucket can stay private, and only CloudFront reads it (see the Load Balancing, DNS and CDN page).

| Approach | HTTPS | Custom domain | Bucket private | Use for |
|---|---|---|---|---|
| S3 website endpoint | No | Via Route 53 alias to the endpoint (HTTP) | No | Quick internal or demo sites |
| CloudFront + OAC | Yes | Yes | Yes | Production sites (recommended) |

## Cost checklist

- Use lifecycle rules, and turn off incomplete multipart uploads: `AbortIncompleteMultipartUpload` after 7 days.
- Check **S3 Storage Lens** for buckets with unexpected growth or noncurrent versions.
- Remember request charges: millions of tiny GETs cost more than the storage.

## Key takeaways

- Buckets are regional and globally named; objects are keyed, and folders are just prefixes.
- Block Public Access, default encryption and versioning are the baseline.
- Use lifecycle rules to move cold data to cheaper classes.
- Share with presigned URLs or CloudFront, never by making the bucket public.
- `ListBucket` uses the bucket ARN; `GetObject` uses `bucket/*`.
